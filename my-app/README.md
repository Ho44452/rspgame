# Rock Paper Scissors

A simple Rock Paper Scissors game built with [Next.js](https://nextjs.org).

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to play. To make changes, edit `app/page.tsx`; the page updates automatically.

## Production

Create an optimized production build and start it locally:

```bash
npm run build
npm run start
```
